# Wavy Text Effect

## Назначение

Этот документ фиксирует, как в проекте реализован волнообразный `wavy`-эффект для текста, чтобы переиспользовать уже существующий механизм, а не собирать его заново в каждом UI-элементе.

## Где находится реализация

- `res://ui/effects/wavy_text_effect.gd` - общий `RichTextEffect`, который обрабатывает тег `[wavy]`.
- `res://ui/vfx/corner_combo_counter.gd` - пример подключения эффекта для счетчика комбо.
- `res://ui/vfx/cascade_tag.gd` - пример подключения эффекта для короткого тегового текста `CASCADE!`.

## Ключевой принцип

Механика уже вынесена в отдельный reusable-компонент: не нужно писать новый шейдер, новую анимацию через `Tween` или отдельный `Label`-контроллер. Правильный путь:

1. Подключить `WavyTextEffect` в `RichTextLabel.custom_effects`.
2. Включить `bbcode_enabled`.
3. Обернуть текст в `[wavy ...]текст[/wavy]`.

## Как работает `wavy_text_effect.gd`

Скрипт наследуется от `RichTextEffect` и регистрирует тег:

```gdscript
extends RichTextEffect
class_name WavyTextEffect

func _init() -> void:
	bbcode = "wavy"
```

Это значит, что любой `RichTextLabel`, в который добавлен этот эффект, начинает понимать BBCode вида:

```text
[wavy amp=3.0 speed=2.2 phase=0.45]COMBO x4[/wavy]
```

Внутри `_process_custom_fx(char_fx)` эффект обрабатывает каждый символ отдельно и меняет:

- `char_fx.offset.y` - вертикальную волну.
- `char_fx.offset.x` - горизонтальное смещение.
- `char_fx.color` - hue/glow-вариации, если они включены параметрами.

## Поддерживаемые параметры

Параметры передаются через BBCode-атрибуты или через `meta`, если это нужно для общего дефолта.

- `amp` - амплитуда вертикальной волны.
- `speed` - скорость основной волны.
- `phase` - сдвиг фазы между символами.
- `len` - длина последовательности символов для step-режима.
- `step_duration` - длительность активной фазы одного символа.
- `step_gap` - пауза между шагами.
- `x_amp` - амплитуда движения по X.
- `x_speed` - скорость движения по X.
- `pulse` - дополнительная пульсация по Y.
- `pulse_speed` - скорость пульсации.
- `hue_amp` - амплитуда смещения hue.
- `hue_speed` - скорость hue-анимации.
- `hue_phase` - фазовый сдвиг hue между символами.
- `glow_amp` - усиление яркости/насыщенности.
- `glow_speed` - скорость glow-анимации.

## Базовый паттерн подключения

Используй тот же шаблон, который уже применяется в проекте:

```gdscript
const WavyTextEffect := preload("res://ui/effects/wavy_text_effect.gd")

@onready var label: RichTextLabel = $MyRichTextLabel

func _ready() -> void:
	label.custom_effects = label.custom_effects + [WavyTextEffect.new()]
	label.bbcode_enabled = true
	label.text = _wrap_wavy("Пример")

func _wrap_wavy(text: String) -> String:
	return "[wavy amp=3.0 speed=2.2 phase=0.45]%s[/wavy]" % text
```

## Как это сделано в проекте сейчас

### `corner_combo_counter.gd`

Текущий reusable-паттерн:

- эффект подключается один раз в `_setup_wave_effects()`;
- любой новый текст проходит через `_wrap_wavy(text)`;
- параметры волны стандартизированы: `amp=3.0 speed=2.2 phase=0.45`.

Это хороший референс, если текст часто обновляется динамически.

### `cascade_tag.gd`

Текущий паттерн для короткой вспышки текста:

- `WavyTextEffect` создается заранее в `@onready`;
- при показе текста строка сразу собирается с `[wavy ...]`;
- исчезновение делается уже отдельно через `Tween`, сам wave-эффект при этом остается на уровне текста.

Это хороший референс, если нужен временный UI-тег.

## Рекомендуемый способ переиспользования

Если нужен новый `wavy`-текст, не создавай новую механику. Делай в таком порядке:

1. Бери `RichTextLabel`, а не обычный `Label`.
2. Подключай `res://ui/effects/wavy_text_effect.gd`.
3. Используй общий helper наподобие `_wrap_wavy(text)`.
4. Если нужны другие ощущения от анимации, меняй только параметры BBCode.

## Готовые пресеты

### Стандартный

```text
[wavy amp=3.0 speed=2.2 phase=0.45]Текст[/wavy]
```

Используется сейчас в `corner_combo_counter.gd` и `cascade_tag.gd`.

### Более мягкий

```text
[wavy amp=1.5 speed=1.6 phase=0.25]Текст[/wavy]
```

Подходит для спокойного UI, где не нужен агрессивный motion.

### Более энергичный

```text
[wavy amp=4.0 speed=3.0 phase=0.6 x_amp=1.0 pulse=0.8]Текст[/wavy]
```

Подходит для коротких акцентных вспышек.

## Когда нужно расширять текущую реализацию

Меняй `res://ui/effects/wavy_text_effect.gd`, только если нового поведения нельзя добиться параметрами. Например:

- нужен новый канал анимации, которого сейчас нет;
- нужно изменить общую математику волны для всех экранов;
- нужен единый новый дефолт для всего проекта.

Если отличается только интенсивность, скорость или цветовая пульсация, достаточно новых параметров в `[wavy ...]`.

## Частые ошибки

- Использовать `Label` вместо `RichTextLabel` - тег `[wavy]` не сработает.
- Забыть `bbcode_enabled = true` - текст покажется как обычная строка с тегами.
- Забыть добавить эффект в `custom_effects` - тег будет неизвестен.
- Писать отдельную логику покадрового смещения текста вместо переиспользования `WavyTextEffect`.

## Короткая формула для будущих задач

Новый волнистый текст в проекте делается не новой механикой, а переиспользованием `res://ui/effects/wavy_text_effect.gd` через `RichTextLabel.custom_effects + [WavyTextEffect.new()]` и BBCode-обертку `[wavy ...]`.
